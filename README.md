\# Salary Prediction MLOps Project



\## Overview

This project predicts employee salaries using Machine Learning and MLOps tools.



\## Project Structure

\- data/ - Dataset

\- models/ - Trained models

\- mlruns/ - MLflow experiments

\- reports/ - Reports and visualizations

\- src/ - Source code



\## Technologies Used

\- Python

\- Pandas

\- Scikit-learn

\- MLflow

\- SHAP

\- Git and GitHub



\## Objective

To build and manage a machine learning pipeline for salary prediction.
